# 经验系统前端开发文档

## 一、文档说明
### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| 所属项目 | 校园墙前端（`qianduan-campus`） |
| 功能名称 | 用户经验条系统 |
| 技术栈 | Vue 3 + Pinia + Element Plus + Vite |
| 主要展示页面 | `src/views/Profile.vue` |
| 关联交互页面 | `src/views/Login.vue`、`src/views/Post/PostPublish.vue`、`src/views/Post/PostDetail.vue` |
| 文档版本 | v1.0 |
| 创建日期 | 2026-07-02 |

### 1.2 功能目标

新增一个经验条系统，经验获取规则如下：

| 行为 | 经验值 |
|------|------|
| 每天首次登录 | `+10` |
| 成功发帖 | `+5` |
| 成功点赞 | `+5` |
| 成功评论 | `+5` |

前端目标：

- 在个人中心展示用户当前经验值、等级、经验条进度
- 在登录、发帖、点赞、评论成功后，及时刷新经验信息
- 不要求修改现有业务表字段，前端仅新增展示与接口调用

## 三、前端展示方案
### 3.1 展示入口

建议把经验条展示在 `Profile.vue` 左侧用户卡片中，放在头像、昵称、角色标签下方。

建议展示内容：

- 当前等级 `level`
- 当前总经验 `exp`
- 当前等级进度条
- 距离下一等级还差多少经验

### 3.2 展示示例

建议后端返回：

```json
{
  "level": 3,
  "currentExp": 42,
  "currentLevelNeedExp": 40,
  "nextLevelNeedExp": 60,
  "currentLevelProgress": 2,
  "currentLevelTotal": 20,
  "progressPercent": 10
}
```

前端展示文案可参考：

- `Lv.3`
- `总经验 42`
- `距离 Lv.4 还差 18 经验`

### 3.3 经验条 UI 建议

建议使用 `el-progress`，避免额外造轮子：

```vue
<div class="exp-panel">
  <div class="exp-panel-header">
    <span class="exp-level">Lv.{{ expInfo.level }}</span>
    <span class="exp-value">{{ expInfo.currentExp }} EXP</span>
  </div>
  <el-progress :percentage="expInfo.progressPercent" :stroke-width="10" />
  <p class="exp-tip">距离下一等级还差 {{ expInfo.nextLevelNeedExp - expInfo.currentExp }} 经验</p>
</div>
```

## 四、接口对接方案
### 4.1 推荐新增接口

| 接口 | 说明 |
|------|------|
| `GET /api/user/exp/info` | 获取当前登录用户经验信息 |
| `GET /api/user/exp/records` | 获取经验明细列表，可选 |

### 4.2 `src/api/user.js` 扩展示例

```javascript
getExpInfo() {
  return request.get('/user/exp/info')
},

getExpRecords(params) {
  return request.get('/user/exp/records', { params })
}
```

如果拆分为 `src/api/exp.js`，也可以写成：

```javascript
import request from '@/utils/request'

export const expAPI = {
  getExpInfo() {
    return request.get('/user/exp/info')
  },

  getExpRecords(params) {
    return request.get('/user/exp/records', { params })
  }
}
```

## 五、页面状态设计
### 5.1 `Profile.vue` 建议新增状态

```javascript
const expLoading = ref(false)

const expInfo = reactive({
  level: 1,
  currentExp: 0,
  currentLevelNeedExp: 0,
  nextLevelNeedExp: 20,
  currentLevelProgress: 0,
  currentLevelTotal: 20,
  progressPercent: 0
})
```

### 5.2 加载经验信息

```javascript
const loadExpInfo = async () => {
  expLoading.value = true
  try {
    const data = await userAPI.getExpInfo()
    Object.assign(expInfo, data || {})
  } finally {
    expLoading.value = false
  }
}
```

### 5.3 页面初始化

建议在 `Profile.vue` 的 `onMounted` 中和 `loadUserInfo()` 一起加载：

```javascript
onMounted(() => {
  loadUserInfo()
  loadExpInfo()
})
```

## 六、交互触发点
### 6.1 登录成功后

位置：`src/views/Login.vue`

登录成功后，后端会在登录逻辑里自动发放“每日首次登录 +10 经验”。  
前端建议在跳转首页前，补一次用户经验信息刷新，或者在进入个人中心时再统一拉取。

推荐策略：

- 登录页不强依赖经验接口
- 个人中心进入时主动拉取 `expInfo`
- 如果后续首页也要显示等级角标，再把经验信息放入 Pinia

### 6.2 发帖成功后

位置：`src/views/Post/PostPublish.vue`

发帖成功后后端自动发放 `+5`。前端建议：

- 发布成功后如果当前页面需要立即展示经验，调用一次 `getExpInfo`
- 如果当前页面不展示经验，可不额外请求，等进入个人中心再刷新

### 6.3 点赞成功后

位置：`src/views/Post/PostDetail.vue`

点赞成功后后端自动发放 `+5`。前端建议：

- 保留现有点赞成功提示
- 如果页面上有等级角标或经验浮层，再补拉一次 `getExpInfo`

注意：

- 只有“真正点赞成功”才应刷新经验
- 如果后端返回“重复点赞”，前端不能当作获得经验成功

### 6.4 评论成功后

位置：`src/views/Post/PostDetail.vue`

评论成功后后端自动发放 `+5`。前端建议：

- 评论成功后刷新评论列表
- 如页面需要同步经验展示，再调用一次 `getExpInfo`

## 七、Pinia 状态建议
### 7.1 是否放入 `userStore`

推荐做法：

- 第一阶段：经验信息只在 `Profile.vue` 内维护，改动最小
- 第二阶段：如果导航栏、帖子页、评论区也要展示等级，再放入 `src/store/user.js`

### 7.2 如需放入全局状态，可扩展为

```javascript
const expInfo = ref(null)

const setExpInfo = (info) => {
  expInfo.value = info
}
```

这样点赞、评论、发帖成功后可以直接刷新全局经验信息。

---

## 八、等级规则展示建议
### 8.1 推荐由后端统一计算

前端不要自行写死等级经验公式，避免后续改规则时需要同步改前端。

前端只负责展示后端返回的：

- 当前等级
- 当前经验
- 当前等级起点经验
- 下一等级所需经验
- 百分比

### 8.2 前端只做兜底展示

例如：

- 接口异常时显示 `Lv.1 / 0 EXP`
- 或直接隐藏经验模块，避免页面报错

## 十、联调约定
### 10.1 成功判断

当前项目拦截器以 `code === 200` 作为成功标准，因此经验接口也必须返回：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

### 10.2 前端不负责经验发放

经验发放必须由后端在业务成功后完成，前端只负责：

- 触发原业务接口
- 根据业务成功结果刷新经验信息
- 展示经验条和经验明细

---

## 十一、验收清单

1. 个人中心可以看到经验条、等级、总经验。
2. 登录成功后，后端可按“每天首次登录 +10”累计经验。
3. 发帖成功后，经验可增加 `5`。
4. 点赞成功后，经验可增加 `5`，重复点赞不重复加经验。
5. 评论成功后，经验可增加 `5`。
6. 前端不依赖修改原有 `user`、`post`、`comment` 表字段。
7. 接口失败时页面不报错，经验模块可降级展示。

---

## 十二、推荐开发顺序

1. 后端先完成经验信息查询接口。
2. 前端在 `Profile.vue` 接入经验条展示。
3. 后端接入登录、发帖、点赞、评论发经验逻辑。
4. 前端在发帖、点赞、评论成功后按需刷新经验信息。
5. 最后补经验明细页或记录弹窗。
