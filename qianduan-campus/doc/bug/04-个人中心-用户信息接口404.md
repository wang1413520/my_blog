# 个人中心用户信息接口 404

## 问题现象

浏览器报错：

```text
GET http://localhost:5174/api/user/info 404 (Not Found)
```

同时页面日志出现：

```text
加载用户信息失败: AxiosError: Request failed with status code 404
```

## 前端请求链路

前端调用位置：

- [src/api/user.js](/C:/Users/lenovo/Desktop/qianduan-campus/src/api/user.js:11)

```js
getUserInfo() {
  return request.get('/user/info')
}
```

axios 基础路径：

- [src/utils/request.js](/C:/Users/lenovo/Desktop/qianduan-campus/src/utils/request.js:6)

```js
baseURL: '/api'
```

因此实际请求地址是：

```text
/api/user/info
```

开发环境中再通过 Vite 代理转发到：

```text
http://localhost:8080/api/user/info
```

## 根因分析

前端请求没写错，Vite 代理也没写错。

真正原因是：后端 `UserController` 中没有实现：

```java
GET /api/user/info
```

当前后端只提供了：

- `POST /api/user/register`
- `POST /api/user/login`
- `PUT /api/user/update`
- `PUT /api/user/password`

缺少个人中心读取当前用户信息的接口。

## 后端应补充的能力

至少需要新增：

```java
@RequireLogin
@GetMapping("/api/user/info")
public Result<UserInfoVO> getUserInfo() { ... }
```

并补齐：

- Service 方法
- Mapper 查询
- `UserInfoVO`

## 是否能只改前端

可以临时让页面使用 `userStore.userInfo` 显示本地缓存，避免空白。

但这不是根本修复，因为：

- 数据可能不完整
- 数据可能不是最新的
- 个人中心按正确设计应从后端获取当前用户完整信息

## 结论

这是后端接口缺失问题，不是前端地址错误。
