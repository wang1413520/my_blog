# 个人中心空值渲染错误

## 问题现象

控制台报错：

```text
Unhandled error during execution of render function
Cannot read properties of null (reading 'username')
```

页面指向 `Profile.vue`。

## 根因分析

`userInfo` 在页面初始化时是：

```js
const userInfo = ref(null)
```

但模板中原来存在这种直接访问：

```vue
<el-input v-model="userInfo.username" disabled />
```

页面第一次渲染时，接口数据还没回来，`userInfo` 仍然是 `null`，因此会触发：

```js
null.username
```

## 本质原因

这是典型的“异步数据还没加载回来，模板先渲染”的问题。

## 处理思路

推荐使用两层防护：

1. 模板中不要直接裸读可能为 `null` 的对象属性
2. 页面在数据加载前先显示骨架屏或占位态

## 已采用方案

- 个人中心头像区和表单区都改成了 `v-if="userInfo"` 后再显示真实内容
- 没有数据时显示 `el-skeleton`
- 用户名输入框改成只读展示，不再直接对 `null` 对象做 `v-model`

## 结论

这是前端空值渲染问题，不是 Vue 框架本身出错。
