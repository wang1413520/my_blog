# 首页与资源页 UI 布局与展示优化记录

## 首页布局问题

### 现象

原来导航从顶部横向菜单改成侧边栏后，出现过布局错乱：

- 侧边栏和主内容方向不对
- 顶部 header 与内容区没有按预期上下排列

### 根因

`el-container` 嵌套后，右侧内容容器方向没有明确指定为纵向。

### 修正思路

- 外层保留左右结构
- 右侧 `content-shell` 使用纵向布局
- 同时补移动端适配

## 首页欢迎卡片颜色问题

### 现象

原来的紫色渐变与整体页面风格不协调。

### 调整方向

- 改成浅橙色主题
- 欢迎区、按钮、边框、卡片阴影都往暖色统一

## 首页按钮交互问题

### 现象

用户希望悬停时按钮有浅蓝色切换效果。

### 处理方式

- 主按钮和次按钮重新统一颜色
- hover 状态加入浅蓝色背景过渡
- 增加轻微上浮和阴影

## 资源页文件封面展示优化

### 现象

资源卡片左侧原来只是普通文件图标，视觉上比较空。

### 已处理方向

- 按文件类型显示不同封面
- 当前已支持：
  - `pdf`
  - `doc`
  - `docx`
- 未匹配类型使用通用封面

### 当前实现方式

- 前端本地 SVG 封面资源
- 根据 `fileType` 做映射
- 不依赖后端缩略图接口

### 后续可升级方向

如果以后想做得更真实，可以继续做：

- PDF 首页缩略图
- Word 预览图
- 课程标签、资料用途标签
- 资料摘要增强
