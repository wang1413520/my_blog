# 小工具箱模块开发文档

## 一、文档说明

### 基本信息

| 项目 | 说明 |
|------|------|
| 所属项目 | 小怀风的小破站（校园墙） |
| 前端技术栈 | Vue 3 + Element Plus + Vite |
| 后端技术栈 | Spring Boot 3 + MySQL |
| 文档版本 | v1.0 |
| 创建日期 | 2026-06-25 |

### 模块概述

**小工具箱** 是一个面向日常开发与办公的轻量级在线工具集合，运行在「小怀风的小破站」前端应用中（无需后端参与，所有转换逻辑在浏览器端完成）。首期核心功能为 **文件/数据格式互相转换工具**，后续逐步扩展更多实用工具。

### 设计原则

- **纯前端运行**：所有转换逻辑在浏览器端完成，不依赖后端接口
- **即开即用**：无需登录即可使用工具箱内的工具
- **本地处理**：用户文件不上传服务器，保障隐私安全
- **渐进增强**：先实现核心转换能力，后续按需扩展工具种类

## 五、工具详情

### 5.1 文本格式互转（Markdown ↔ HTML）

**组件**：`TextConvert.vue`

| 功能 | 说明 |
|------|------|
| Markdown → HTML | 使用 `marked` 库将 Markdown 渲染为 HTML |
| HTML → Markdown | 使用 `turndown` 库将 HTML 转换为 Markdown |
| 双向编辑 | 左右分栏布局，一侧编辑一侧预览 |
| 复制结果 | 一键复制转换后的内容 |
| 清空重置 | 一键清空输入内容 |

**界面布局**：

```
+-------------------------------------------+
|  [Markdown → HTML]  [HTML → Markdown]   ← 模式切换 |
+-------------------------------------------+
|  输入区域 (textarea)  |  输出区域 (预览/源码)   |
|  源码编辑区           |  实时渲染结果           |
|                       |                        |
+-------------------------------------------+
|      [清空]  [复制结果]                     |
+-------------------------------------------+
```

**核心代码示例**：

```javascript
import { ref, computed } from 'vue'
import { marked } from 'marked'
import TurndownService from 'turndown'

const turndownService = new TurndownService()

// Markdown → HTML
const mdToHtml = (mdText) => {
  return marked.parse(mdText)
}

// HTML → Markdown
const htmlToMd = (htmlText) => {
  return turndownService.turndown(htmlText)
}
```

### 5.2 JSON 格式化/校验

**组件**：`JsonFormatter.vue`

| 功能 | 说明 |
|------|------|
| JSON 格式化 | 格式化 JSON 字符串（可配置缩进） |
| JSON 压缩 | 去除空格和换行，压缩成单行 |
| JSON 校验 | 检测 JSON 语法错误并提示位置 |
| 复制结果 | 一键复制格式化后的 JSON |

**核心实现**：使用 `JSON.parse()` 校验，`JSON.stringify(obj, null, indent)` 格式化。

### 5.3 JSON ↔ YAML 互转

**组件**：`JsonYamlConvert.vue`

| 功能 | 说明 |
|------|------|
| JSON → YAML | 将 JSON 解析后序列化为 YAML |
| YAML → JSON | 将 YAML 解析后序列化为 JSON |

**核心代码示例**：

```javascript
import yaml from 'js-yaml'

// JSON → YAML
const jsonToYaml = (jsonStr) => {
  const obj = JSON.parse(jsonStr)
  return yaml.dump(obj, { indent: 2 })
}

// YAML → JSON
const yamlToJson = (yamlStr) => {
  const obj = yaml.load(yamlStr)
  return JSON.stringify(obj, null, 2)
}
```

### 5.4 Base64 编解码

**组件**：`Base64Tool.vue`

| 功能 | 说明 |
|------|------|
| 文本 Base64 编码 | 将普通文本编码为 Base64 |
| 文本 Base64 解码 | 将 Base64 解码为原文 |
| 文件 Base64 编码 | 将上传的文件转为 Base64（用于 data URI） |
| 复制结果 | 一键复制编码/解码结果 |
| 文件上传 | 支持拖拽或点击上传文件 |

**核心代码示例**：

```javascript
// 文本编码
const encode = (text) => btoa(unescape(encodeURIComponent(text)))

// 文本解码
const decode = (base64) => decodeURIComponent(escape(atob(base64)))

// 文件转 Base64
const fileToBase64 = (file) => {
  return new Promise((resolve, reject) => {
    const reader = new FileReader()
    reader.onload = () => resolve(reader.result)
    reader.onerror = reject
    reader.readAsDataURL(file)
  })
}
```

### 5.5 时间戳转换

**组件**：`TimestampConvert.vue`

| 功能 | 说明 |
|------|------|
| 时间戳 → 日期 | 将 Unix 时间戳（秒/毫秒）转为可读日期 |
| 日期 → 时间戳 | 将日期时间字符串转为 Unix 时间戳 |
| 当前时间戳 | 一键获取当前时间戳（秒/毫秒） |
| 多种格式 | 支持多种日期格式输出 |
| 复制结果 | 一键复制时间戳或日期 |

**核心实现**：使用 `dayjs`（已有依赖）或原生 `Date` 对象进行转换。

### 5.6 颜色格式转换

**组件**：`ColorConvert.vue`

| 功能 | 说明 |
|------|------|
| HEX → RGB | `#FF0000` → `rgb(255, 0, 0)` |
| RGB → HEX | `rgb(255, 0, 0)` → `#FF0000` |
| HEX → HSL | `#FF0000` → `hsl(0, 100%, 50%)` |
| HSL → HEX | `hsl(0, 100%, 50%)` → `#FF0000` |
| 颜色预览 | 实时显示转换结果的颜色色块 |
| 复制结果 | 一键复制任意格式的颜色值 |

## 九、注意事项

### 9.1 安全相关

- **不上传文件**：所有文件转换在浏览器本地完成，不得将用户文件发送到后端
- **XSS 防范**：使用 `marked` 时设置 `sanitize` 选项，防止 Markdown 中的 XSS 攻击
- **超大文件**：Base64 编码大文件时需提示用户文件大小限制（建议不超过 10MB）

### 9.2 性能优化

- `marked` 和 `turndown` 采用懒加载（动态 `import()`），仅在进入对应工具页面时加载
- Markdown 渲染可加 `debounce`（300ms）避免高频输入频繁重渲染

### 9.3 marked 安全配置

```javascript
marked.setOptions({
  breaks: true,        // 支持 GitHub 风格的换行
  gfm: true,           // 启用 GitHub 风格 Markdown
})
```
