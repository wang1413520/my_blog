# 我的资料前端开发文档

## 一、文档说明
### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| 所属项目 | 校园墙前端（`qianduan-campus`） |
| 模块名称 | 个人中心 - 我的资料 |
| 技术栈 | Vue 3 + Element Plus + Vite |
| 关联页面 | `src/views/Profile.vue` |
| 对接后端 | `GET /api/user/profile/detail`、`PUT /api/user/profile/detail` |
| 文档版本 | v1.0 |
| 创建日期 | 2026-06-27 |

### 1.2 开发目标

在现有“个人信息 / 修改密码”基础上，新增一个“我的资料”功能入口，用于维护用户更完整的个人档案信息，和基础账号信息分开展示。

本次前端改造目标：

- 不影响现有“个人信息”和“修改密码”功能
- 左侧菜单新增“我的资料”入口
- 右侧新增“我的资料”表单页
- 页面数据支持加载、编辑、保存
- 保持当前个人中心页面视觉风格一致

## 三、功能设计
### 3.1 功能定位

“个人信息”继续负责账号级信息维护：

- 用户名（只读）
- 昵称
- 头像

“我的资料”负责个人档案信息维护，建议包括：

- 真实姓名 `realName`
- 性别 `gender`
- 出生日期 `birthday`
- 手机号 `phone`
- 邮箱 `email`
- 学校 `school`
- 学院 `college`
- 专业 `major`
- 年级 `grade`
- 所在城市 `location`
- 个人简介 `bio`

### 3.2 页面交互

用户流程：

1. 用户进入“我的”页面
2. 点击左侧菜单“我的资料”
3. 前端展示“我的资料”表单
4. 首次进入时调用后端接口加载资料详情
5. 用户修改资料后点击“保存资料”
6. 前端调用保存接口
7. 保存成功后提示成功信息

### 3.3 空数据策略

如果用户此前从未填写过资料：

- 后端仍返回 `code = 200`
- `data` 返回空字段或默认值
- 前端直接渲染空表单，不视为异常

## 六、接口对接说明
### 6.1 查询资料详情

- 请求方式：`GET`
- 请求路径：`/api/user/profile/detail`
- 是否需要登录：是

前端调用建议：

```javascript
const loadProfileDetail = async () => {
  profileDetailLoading.value = true
  try {
    const data = await userAPI.getProfileDetail()
    Object.assign(profileForm, {
      realName: data.realName || '',
      gender: data.gender || '',
      birthday: data.birthday || '',
      phone: data.phone || '',
      email: data.email || '',
      school: data.school || '',
      college: data.college || '',
      major: data.major || '',
      grade: data.grade || '',
      location: data.location || '',
      bio: data.bio || ''
    })
    profileDetailLoaded.value = true
  } finally {
    profileDetailLoading.value = false
  }
}
```

### 6.2 保存资料

- 请求方式：`PUT`
- 请求路径：`/api/user/profile/detail`
- 是否需要登录：是

前端提交数据示例：

```javascript
await userAPI.updateProfileDetail({
  realName: profileForm.realName,
  gender: profileForm.gender,
  birthday: profileForm.birthday,
  phone: profileForm.phone,
  email: profileForm.email,
  school: profileForm.school,
  college: profileForm.college,
  major: profileForm.major,
  grade: profileForm.grade,
  location: profileForm.location,
  bio: profileForm.bio
})
```

### 6.3 `src/api/user.js` 扩展建议

新增接口方法：

```javascript
getProfileDetail() {
  return request.get('/user/profile/detail')
},

updateProfileDetail(data) {
  return request.put('/user/profile/detail', data)
}
```

## 七、表单校验规则
### 7.1 建议规则

| 字段 | 是否必填 | 规则建议 |
|------|----------|----------|
| realName | 否 | 最长 30 字 |
| gender | 否 | 仅允许 `male/female/unknown` |
| birthday | 否 | 合法日期 |
| phone | 否 | 手机号格式校验 |
| email | 否 | 邮箱格式校验 |
| school | 否 | 最长 100 字 |
| college | 否 | 最长 100 字 |
| major | 否 | 最长 100 字 |
| grade | 否 | 最长 30 字 |
| location | 否 | 最长 100 字 |
| bio | 否 | 最长 300 字 |

### 7.2 前端规则示例

```javascript
const profileRules = {
  phone: [
    {
      pattern: /^1\d{10}$/,
      message: '请输入正确的手机号',
      trigger: 'blur'
    }
  ],
  email: [
    {
      type: 'email',
      message: '请输入正确的邮箱地址',
      trigger: 'blur'
    }
  ],
  bio: [
    {
      max: 300,
      message: '个人简介不能超过 300 个字符',
      trigger: 'blur'
    }
  ]
}
```

注意：

- 所有字段都建议支持空值，避免用户被强制填写
- 前端校验只做基础体验增强，最终以后端校验为准

## 八、加载与切换策略
### 8.1 菜单切换行为

当前 `handleMenuSelect`：

```javascript
const handleMenuSelect = (index) => {
  activeMenu.value = index
}
```

建议改造为：

```javascript
const handleMenuSelect = async (index) => {
  activeMenu.value = index

  if (index === 'profile' && !profileDetailLoaded.value) {
    await loadProfileDetail()
  }
}
```

### 8.2 加载体验建议

- 第一次进入“我的资料”时展示骨架屏或表单 loading
- 再次切换回“我的资料”时优先使用本地已加载数据
- 如果保存成功，不强制再次调用查询接口，可直接保留当前表单值

## 十、联调约束
### 10.1 请求成功判断

当前项目 `src/utils/request.js` 中只有 `code === 200` 才会进入成功分支，因此后端必须保证：

- 查询成功：`code = 200`
- 首次无资料但允许编辑：`code = 200`
- 保存成功：`code = 200`

### 10.2 日期字段格式

前后端统一建议使用：

- 返回值：`yyyy-MM-dd`
- 提交值：`yyyy-MM-dd`

这样可直接配合 `el-date-picker` 使用，减少转换成本。
