# 个人博客前端项目

基于 Vue 3 + Element Plus 开发的个人博客前端应用。

## 技术栈

- Vue 3
- Vue Router
- Pinia
- Element Plus
- Axios
- Vite

## 项目结构

```text
src/
├── api/                # API 接口封装
│   ├── user.js
│   ├── post.js
│   ├── comment.js
│   ├── resource.js
│   ├── memo.js
│   └── admin.js
├── assets/             # 静态资源
├── components/         # 公共组件
├── router/             # 路由配置
├── store/              # 状态管理
├── utils/              # 工具函数
├── views/              # 页面组件
│   ├── Login.vue
│   ├── Layout.vue
│   ├── Home.vue
│   ├── Profile.vue
│   ├── Post/
│   ├── Resource/
│   ├── Toolbox/
│   └── Admin/
├── App.vue
└── main.js
```

## 开发命令

安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 接口配置

接口基地址通过环境变量控制：

```text
VITE_API_BASE_URL=/api
```

默认文件：

- `.env`
- `.env.production`

当前 `src/utils/request.js` 会读取：

```javascript
baseURL: import.meta.env.VITE_API_BASE_URL || '/api'
```

## 生产部署说明

本项目生产环境必须配置：

- `/api` 反向代理到后端服务
- `try_files $uri $uri/ /index.html;`

详细部署说明见：

```text
doc/前端上线部署说明.md
```

## 注意事项

1. 后端服务需正常运行
2. 登录后 token 会保存到 `localStorage`
3. 需要登录的页面会自动跳转到登录页
4. 上传文件大小需受服务端和 Nginx 限制共同约束
5. 生产环境不要依赖 Vite dev proxy
