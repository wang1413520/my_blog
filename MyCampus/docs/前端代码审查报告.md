## 二、🔴 致命问题

### 问题 1：`src/api/resource.js:32` — 下载链接硬编码 localhost

**当前代码：**
```javascript
downloadResource(id) {
    return `http://localhost:8080/api/resource/download/${id}`
},
```

**问题：** 线上部署后，用户浏览器访问 `http://localhost:8080/...` 会指向用户自己的电脑，而非服务器，下载功能完全失效。

**触发场景：**
- `ResourceList.vue` 第 993 行：`handleDownload(id)`
- `Profile.vue` 第 1148 行：`handleResourceDownload(id)`（"我的资源"页面）

**修复方案：** 改为相对路径：
```javascript
downloadResource(id) {
    return `/api/resource/download/${id}`
},
```

**说明：** `request.js` 已经配置了 `baseURL: '/api'`，但 `downloadResource` 绕过了 axios 直接用 `window.open()` 打开链接，所以必须改为相对路径才能被 nginx 正确代理。

## 三、🟡 中等问题

### 问题 2：`vite.config.js` 的 proxy 只对 dev 生效

**当前代码：**
```javascript
server: {
    proxy: {
        '/api': {
            target: 'http://localhost:8080',
            changeOrigin: true,
            rewrite: (path) => path
        }
    }
}
```

**问题：** Vite proxy 只在 `npm run dev` 时生效。`npm run build` 产出的是纯静态文件，不包含任何代理逻辑。生产环境必须用 Nginx 配置反向代理。

**需要的 Nginx 配置：**
```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    client_max_body_size 550m;
}
```

### 问题 3：`src/router/index.js:75` — History 模式需要服务端 fallback

**当前代码：**
```javascript
const router = createRouter({
    history: createWebHistory(),  // ← HTML5 History 模式
    routes
})
```

**问题：** 用户直接访问 `/post/detail/123` 或刷新页面时，Nginx 找不到对应的静态文件会返回 404。

**需要的 Nginx 配置：**
```nginx
location / {
    root /opt/qianduan-campus/dist;
    index index.html;
    try_files $uri $uri/ /index.html;  # ← 这一行必须加
}
```

### 问题 9：缺少环境变量管理

**现状：** 没有 `.env` / `.env.production` 文件，`baseURL` 硬编码在 `request.js` 中。

**建议：** 使用 Vite 的环境变量：
```javascript
// .env
VITE_API_BASE_URL=/api

// .env.production
VITE_API_BASE_URL=/api

// request.js
baseURL: import.meta.env.VITE_API_BASE_URL || '/api',
```

这样不同环境可以灵活切换 API 地址。

## 四、🟢 建议优化

### 问题 10：`MemoBoard.vue` — 未登录用户体验不佳

**现象：** 未登录用户访问首页，备忘录区域加载后显示空状态 "还没有备忘录"。实际原因是没有登录态导致接口 401。

**流程：**
```
未登录 → loadMemos() → memoAPI.getMemoList()
→ 后端返回 401 → request.js 拦截器弹出 "登录已过期"
→ memos.value = [] → 显示 "还没有备忘录"
```

**建议：** 未登录时隐藏备忘录区域，或显示 "登录后可创建备忘录" 并引导登录。

---

**当前代码：**

<p>&copy; 2026 小怀风的博客. Built with Vue 3.</p>

`© ${new Date().getFullYear()} 小怀风的博客`

### 问题 12：`dist/index.html` — 构建产物的 lang 和 title 同上

`dist/index.html` 是 `index.html` 的构建产物，重构后需重新 `npm run build` 才会更新。

---

### 问题 13：下载功能无进度提示

`handleDownload` 使用 `window.open(url, '_blank')` 直接打开，部分浏览器可能拦截弹窗。大文件下载没有进度反馈。

**建议：** 改为 `<a>` 标签下载或使用 `fetch` + `Blob` 下载。
