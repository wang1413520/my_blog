# 小工具箱模块后端开发文档

## 一、文档说明

### 基本信息

| 项目 | 说明 |
|------|------|
| 所属项目 | 校园墙（Campus Wall） |
| 基础包名 | `com.wang.mycampus` |
| 后端框架 | Spring Boot 3.5 + MyBatis + MySQL |
| 接口基础路径 | `http://localhost:8080/api/toolbox` |
| 认证方式 | JWT Token（请求头 `Authorization: Bearer {token}`） |
| 数据格式 | JSON |
| 文档版本 | v1.0 |
| 创建日期 | 2026-06-25 |

### 统一返回格式

沿用现有 `Result<T>` 统一响应：

```json
{
    "code": 200,
    "message": "操作成功",
    "data": {}
}
```

### 模块定位

**小工具箱后端** 负责处理前端无法完成的文件转换任务，包括：

- 文档格式转换（PDF ↔ Word、PDF ↔ 图片、Word ↔ Markdown 等）
- 图片格式/尺寸转换（PNG ↔ JPG ↔ WebP、缩放裁剪等）
- 视频/音频转码（可选，v2.0）
- 文件在线预览（PDF 转图片预览等）
- 转换历史记录管理

> 纯前端的工具（JSON 格式化、Base64 编解码、时间戳转换等）**无需后端参与**，见《小工具箱开发文档》前端部分。

## 二、涉及范围划分

### 2.1 纯前端（无后端接口）

| 工具 | 原因 |
|------|------|
| JSON 格式化/校验 | `JSON.parse/stringify` 原生支持 |
| JSON ↔ YAML | js-yaml 库，浏览器端运行 |
| Base64 编解码 | `btoa/atob` 原生支持 |
| 时间戳转换 | dayjs + Date 原生支持 |
| 颜色格式转换 | 纯计算，无依赖 |
| Markdown ↔ HTML | marked + turndown 库 |

### 2.2 需要后端接口

| 工具 | 后端职责 |
|------|---------|
| PDF ↔ Word | 上传 → 后端转换 → 返回下载链接 |
| PDF ↔ 图片 | 上传 → 后端渲染 → 返回图片/ZIP |
| Word ↔ Markdown | 上传 → 后端解析 → 返回文本/文件 |
| 图片格式转换 | 上传 → 后端转换 → 返回新格式文件 |
| 图片压缩 | 上传 → 后端压缩 → 返回压缩文件 |
| 文件合并/拆分 | 上传多个文件 → 后端合并/拆分 → 返回 |

## 四、数据库设计

### 4.1 转换记录表 `convert_record`

```sql
CREATE TABLE convert_record (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    user_id     BIGINT       NOT NULL                COMMENT '用户ID（可为空，未登录用户）',
    source_name VARCHAR(255) NOT NULL                COMMENT '源文件名',
    source_type VARCHAR(20)  NOT NULL                COMMENT '源文件格式（pdf/docx/png...）',
    target_type VARCHAR(20)  NOT NULL                COMMENT '目标文件格式',
    status      TINYINT      NOT NULL DEFAULT 0      COMMENT '状态：0-转换中 1-成功 2-失败',
    source_url  VARCHAR(500) NOT NULL                COMMENT '源文件 OSS URL',
    result_url  VARCHAR(500) DEFAULT NULL            COMMENT '结果文件 OSS URL',
    file_size   BIGINT       DEFAULT 0               COMMENT '源文件大小（字节）',
    error_msg   VARCHAR(500) DEFAULT NULL            COMMENT '失败原因',
    created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at)
) COMMENT '文件转换记录表';
```

> 注：v1.0 不设配额限制。转换消耗的是服务器 CPU/内存和 OSS 存储空间，对于个人站用量来说基本可以忽略，无需过度设计配额体系。

### 5.2 可选的文档转换方案

如果需要更丰富的文档转换能力（如 Word ↔ PDF、HTML ↔ PDF），有以下方案可选：

| 方案 | 说明 | 性能 | 部署复杂度 |
|------|------|------|-----------|
| **Apache POI + PDFBox** | 纯 Java，不需要外部程序 | 中等 | 低 |
| **LibreOffice headless** | 调用系统安装的 LibreOffice 命令行 | 较慢 | 高（需装 LibreOffice） |
| **Aspose** | 商业库，功能最全 | 快 | 低（需付费授权） |

> **v1.0 建议使用 Apache POI + PDFBox 方案**，零外部依赖。后续如果需要更复杂格式的转换，再引入 LibreOffice 方案。

## 六、接口设计

### 6.1 文件转换接口（统一入口）

**说明**：前端上传源文件，指定目标格式，后端转换后返回结果文件的 OSS URL。

```
POST /api/toolbox/convert
```

**请求头**：`Authorization: Bearer {token}`（可选，未登录用户也可以转换，但有次数限制）

**请求参数**（`multipart/form-data`）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | MultipartFile | 是 | 要转换的源文件 |
| targetType | String | 是 | 目标格式，如 `pdf`、`docx`、`png`、`jpg`、`md`、`txt` |
| quality | Integer | 否 | 图片质量 1-100（仅图片转换有效，默认 90） |
| width | Integer | 否 | 图片宽度（仅图片转换有效，默认原图） |
| height | Integer | 否 | 图片高度（仅图片转换有效，默认原图） |

**响应**：

```json
{
    "code": 200,
    "message": "操作成功",
```

```java
@RestController

public class ToolboxController {

    @Autowired
    private ToolboxService toolboxService;

     * 6.1 文件转换入口

    public Result<ConvertResultVO> convertFile(

            @RequestParam("targetType") String targetType,
            @RequestParam(value = "quality", defaultValue = "90") Integer quality,
            @RequestParam(value = "width", required = false) Integer width,

        ConvertResultVO result = toolboxService.convertFile(file, targetType, quality, width, height, userId);

        Long userId = UserContext.getUserId();
        PageVO<ConvertHistoryVO> history = toolboxService.getConvertHistory(userId, page, size);
        return Result.success(history);
    }

     * 6.3 获取支持的转换格式
     */
    @GetMapping("/convert/supported-types")
    public Result<Map<String, Object>> getSupportedTypes() {
        return Result.success(toolboxService.getSupportedTypes());

    /**
     * 6.4 删除转换记录
     */
```

### 7.2 转换核心逻辑——Service

```java
@Service
@Slf4j
public class ToolboxServiceImpl implements ToolboxService {

    @Autowired
    private OSS ossClient;

    @Autowired
    private OssConfig ossConfig;

    @Autowired
    private ConvertRecordMapper convertRecordMapper;

    @Autowired
    private ConvertConfig convertConfig;

    private static final Map<String, String> SUPPORTED_CONVERSIONS = new LinkedHashMap<>();

    static {
        // 文档类
        SUPPORTED_CONVERSIONS.put("pdf2docx", "pdf → Word");
        SUPPORTED_CONVERSIONS.put("pdf2png",  "pdf → 图片");
        SUPPORTED_CONVERSIONS.put("docx2pdf", "Word → pdf");
        SUPPORTED_CONVERSIONS.put("docx2md",  "Word → Markdown");
        SUPPORTED_CONVERSIONS.put("md2pdf",   "Markdown → pdf");
        SUPPORTED_CONVERSIONS.put("md2html",  "Markdown → HTML");

        // 图片类
        SUPPORTED_CONVERSIONS.put("img2img",  "图片格式互转");
    }

    @Override
    public ConvertResultVO convertFile(MultipartFile file, String targetType,
                                       Integer quality, Integer width, Integer height,
                                       Long userId) throws IOException {

        String originalName = file.getOriginalFilename();
        String sourceType = extractExtension(originalName).toLowerCase();
        long fileSize = file.getSize();

        // 1. 校验转换合法性
        validateConversion(sourceType, targetType, fileSize);

        // 2. 将源文件上传到 OSS 临时目录（保留原始文件，方便重试）
        String sourceFileName = generateFileName(sourceType);
        String sourceUrl = uploadToOss(file.getInputStream(), sourceFileName);

        // 3. 写入转换记录（状态：转换中）
        ConvertRecord record = new ConvertRecord();
        record.setUserId(userId);
        record.setSourceName(originalName);
        record.setSourceType(sourceType);
        record.setTargetType(targetType);
        record.setStatus(0);
        record.setSourceUrl(sourceUrl);
        record.setFileSize(fileSize);
        convertRecordMapper.insert(record);

        try {
            // 4. 执行转换
            byte[] convertedBytes = doConvert(file.getInputStream(), sourceType, targetType, quality, width, height);

            // 5. 上传转换结果到 OSS
            String resultFileName = generateFileName(targetType);
            String resultUrl = uploadToOss(new ByteArrayInputStream(convertedBytes), resultFileName);

            // 6. 更新记录为成功
            record.setStatus(1);
            record.setResultUrl(resultUrl);
            convertRecordMapper.updateById(record);

            // 7. 构建 VO 返回
            ConvertResultVO vo = new ConvertResultVO();
            vo.setRecordId(record.getId());
            vo.setSourceName(originalName);
            vo.setSourceType(sourceType);
            vo.setTargetType(targetType);
            vo.setStatus(1);
            vo.setResultUrl(resultUrl);
            vo.setFileSize((long) convertedBytes.length);
            return vo;

        } catch (Exception e) {
            log.error("文件转换失败: source={}, target={}, error={}", sourceType, targetType, e.getMessage());

            record.setStatus(2);
            record.setErrorMsg(e.getMessage());
            convertRecordMapper.updateById(record);

            throw new BaseException("文件转换失败: " + e.getMessage());
        }
    }

    /**
     * 实际转换方法——根据不同格式路由到不同转换器
     */
    private byte[] doConvert(InputStream inputStream, String sourceType,
                             String targetType, Integer quality,
                             Integer width, Integer height) throws Exception {

        String key = sourceType + "2" + targetType;

        switch (key) {
            // === PDF 转换 ===
            case "pdf2docx":
                return pdfToDocx(inputStream);
            case "pdf2png":
            case "pdf2jpg":
                return pdfToImage(inputStream, targetType, width, height);
            case "pdf2txt":
                return pdfToText(inputStream);

            // === Word 转换 ===
            case "docx2pdf":
                return docxToPdf(inputStream);
            case "docx2md":
            case "doc2md":
                return docxToMarkdown(inputStream);
            case "docx2txt":
                return docxToText(inputStream);

            // === Markdown 转换 ===
            case "md2html":
                return markdownToHtml(inputStream);
            case "md2pdf":
                return markdownToPdf(inputStream);

            // === 图片转换 ===
            case "png2jpg":
            case "png2jpeg":
            case "png2webp":
            case "jpg2png":
            case "jpg2webp":
            case "jpeg2png":
            case "jpeg2webp":
            case "webp2png":
            case "webp2jpg":
            case "bmp2png":
            case "bmp2jpg":
                return convertImage(inputStream, targetType, quality, width, height);

            default:
                throw new UnsupportedOperationException("不支持的转换类型: " + sourceType + " → " + targetType);
        }
    }
}
```

### 7.3 各转换实现要点

#### PDF → Word（提取文本内容）

```java
private byte[] pdfToDocx(InputStream inputStream) throws Exception {
    // 1. 用 PDFBox 读取 PDF
    try (PDDocument document = PDDocument.load(inputStream)) {
        PDFTextStripper stripper = new PDFTextStripper();
        String text = stripper.getText(document);

        // 2. 用 Apache POI 写入 Word
        XWPFDocument doc = new XWPFDocument();
        XWPFParagraph paragraph = doc.createParagraph();
        XWPFRun run = paragraph.createRun();
        run.setText(text);

        // 3. 输出字节流
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        doc.write(baos);
        return baos.toByteArray();
    }
}
```

#### PDF → 图片

```java
private byte[] pdfToImage(InputStream inputStream, String targetType,
                          Integer width, Integer height) throws Exception {
    try (PDDocument document = PDDocument.load(inputStream)) {
        PDFRenderer renderer = new PDFRenderer(document);

        // 如果有多页，将所有页面合并为一张长图或打包为 ZIP
        // 简单场景：只转换第一页
        BufferedImage image = renderer.renderImageWithDPI(0, 150); // 150 DPI

        // 缩放（如指定宽高）
        if (width != null && height != null) {
            image = Thumbnails.of(image).size(width, height).asBufferedImage();
        }

        // 编码为目标格式
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        String format = "png".equals(targetType) ? "png" : "jpg";
        ImageIO.write(image, format, baos);
        return baos.toByteArray();
    }
}
```

#### Word → Markdown

```java
private byte[] docxToMarkdown(InputStream inputStream) throws Exception {
    XWPFDocument document = new XWPFDocument(inputStream);
    StringBuilder mdBuilder = new StringBuilder();

    for (XWPFParagraph paragraph : document.getParagraphs()) {
        String style = paragraph.getStyle();
        String text = paragraph.getText().trim();

        if (text.isEmpty()) continue;

        // 根据样式转 Markdown 标记
        if ("Heading1".equals(style))       mdBuilder.append("# ");
        else if ("Heading2".equals(style))  mdBuilder.append("## ");
        else if ("Heading3".equals(style))  mdBuilder.append("### ");
        // ... 更多样式映射

        mdBuilder.append(text).append("\n\n");
    }

    return mdBuilder.toString().getBytes(StandardCharsets.UTF_8);
}
```

#### 图片格式转换

```java
private byte[] convertImage(InputStream inputStream, String targetType,
                            Integer quality, Integer width, Integer height) throws Exception {
    BufferedImage image = ImageIO.read(inputStream);
    if (image == null) {
        throw new BaseException("无法读取图片文件");
    }

    // 缩放
    if (width != null && height != null) {
        image = Thumbnails.of(image).size(width, height).asBufferedImage();
    }

    ByteArrayOutputStream baos = new ByteArrayOutputStream();

    // JPEG 特殊处理——需要将 ARGB 转为 RGB
    if ("jpg".equals(targetType) || "jpeg".equals(targetType)) {
        BufferedImage rgbImage = new BufferedImage(image.getWidth(), image.getHeight(),
                BufferedImage.TYPE_INT_RGB);
        rgbImage.createGraphics().drawImage(image, 0, 0, Color.WHITE, null);
        image = rgbImage;
    }

    // 写入目标格式
    ImageIO.write(image, targetType, baos);
    return baos.toByteArray();
}
```

```yaml
      max-request-size: 55MB
```

### 10.2 超时处理

- 大文件转换（如数百页 PDF → Word）可能耗时较长，建议：
  - **同步模式**（v1.0 简单实现）：前端显示"转换中"状态，接口等到转换完成返回
  - **异步模式**（v2.0 优化）：接口立即返回 `status=0`（转换中），前端轮询查询结果

### 10.3 OSS 文件清理

- 转换结果文件建议设置 OSS 生命周期规则，7 天后自动删除
- 或在删除转换记录时同步清理 OSS 文件

### 10.4 转换时间

- 大文件转换（如数百页 PDF）可能耗时数秒到数十秒，前端需要展示加载状态

### 10.5 PDFBox 中文支持

- PDFBox 提取中文 PDF 时可能需要中文字体支持
- 在服务器上安装中文字体：`fonts-noto-cjk` 或 `fonts-wqy-zenhei`
