## 三、后端上线准备

### 3.1 生产环境配置

已创建 `application-prod.yml`，所有敏感信息通过环境变量注入。

**启动前必须设置的环境变量：**

```bash
export DB_PASSWORD="你的数据库密码"
export OSS_ACCESS_KEY_ID="你的OSS AccessKey"
export OSS_ACCESS_KEY_SECRET="你的OSS Secret"
export DB_URL="jdbc:mysql://localhost:3306/my_web_school_project"
```

**启动命令：**

```bash
java -jar MyCampus-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod
```

### 3.2 如果服务器没有 LibreOffice / wkhtmltopdf

工具箱的文件转换功能依赖这两个工具。如果不使用文件转换功能：

**方案A：注释掉相关配置**，启动时 Spring Boot 不会加载这些配置（只要 `ConvertConfig` 有 `@ConditionalOnProperty` 或相关 Bean 可以不存在）。

**方案B：在服务器上安装：**

```bash
# LibreOffice（CentOS/RHEL）
yum install -y libreoffice-headless

# LibreOffice（Ubuntu/Debian）
apt install -y libreoffice-headless

# wkhtmltopdf（Ubuntu/Debian）
apt install -y wkhtmltopdf

# wkhtmltopdf（CentOS/RHEL — 需要手动下载安装）
wget https://github.com/wkhtmltopdf/packaging/releases/download/0.12.6.1-3/wkhtmltox-0.12.6.1-3.almalinux8.x86_64.rpm
rpm -ivh wkhtmltox-*.rpm
```

### 3.3 打包

```bash
cd MyCampus
mvn clean package -DskipTests
# JAR 位置：target/MyCampus-0.0.1-SNAPSHOT.jar
```

## 四、Nginx 配置参考

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名或 IP

    # 前端静态文件
    location / {
        root /opt/qianduan-campus/dist;
        index index.html;
        try_files $uri $uri/ /index.html;  # SPA fallback（必须！）
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 文件上传大小限制
        client_max_body_size 550m;
    }
}
```

### 为什么 `try_files` 必须配？

前端使用 Vue Router 的 `createWebHistory()` 模式。当用户直接访问 `/post/detail/123` 时，nginx 找不到这个文件，会返回 404。`try_files $uri $uri/ /index.html` 让所有路径都 fallback 到 `index.html`，由前端路由接管。

## 五、云服务器部署步骤

### 5.1 服务器环境准备

```bash
# 1. 安装 Java 17
# Ubuntu/Debian
apt install openjdk-17-jdk-headless

# CentOS/RHEL
yum install java-17-openjdk-headless

# 2. 安装 Nginx
apt install nginx  # 或 yum install nginx

# 3. 安装 MySQL（如果尚未安装）
apt install mysql-server
```

### 5.2 上传文件

```bash
# 后端 JAR
scp target/MyCampus-0.0.1-SNAPSHOT.jar user@server:/opt/myblog/

# 前端 dist
scp -r dist/* user@server:/opt/myblog/dist/

# SQL 脚本
scp src/main/resources/init-schema.sql user@server:/opt/myblog/
scp src/main/resources/migration-folder-upload.sql user@server:/opt/myblog/
scp docs/memo.sql user@server:/opt/myblog/
scp docs/user_profile_detail.sql user@server:/opt/myblog/
```

### 5.3 服务器操作

```bash
# 1. 建表
mysql -u root -p my_web_school_project < /opt/myblog/init-schema.sql
mysql -u root -p my_web_school_project < /opt/myblog/migration-folder-upload.sql
mysql -u root -p my_web_school_project < /opt/myblog/memo.sql
mysql -u root -p my_web_school_project < /opt/myblog/user_profile_detail.sql

# 2. 配置环境变量
export DB_PASSWORD="你的数据库密码"
export OSS_ACCESS_KEY_ID="你的AK"
export OSS_ACCESS_KEY_SECRET="你的SK"

# 3. 启动后端
nohup java -jar /opt/myblog/MyCampus-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod > /opt/myblog/app.log 2>&1 &

# 4. 配置 Nginx
cp nginx.conf /etc/nginx/sites-available/myblog
ln -s /etc/nginx/sites-available/myblog /etc/nginx/sites-enabled/
nginx -t && nginx -s reload
```

### 5.4 验证

```bash
# 1. 后端健康检查
curl http://localhost:8080/api/home/stats

# 2. 前端页面
curl http://localhost/

# 3. 查看日志
tail -f /opt/myblog/app.log
```

## 六、安全建议

| 事项 | 说明 |
|------|------|
| **数据库密码** | 使用强密码（如字母+数字+符号组合），通过环境变量 `DB_PASSWORD` 注入 |
| **OSS 密钥** | 已在代码中暴露的 AK/SK 建议在阿里云控制台禁用并换新的 |
| **MySQL 端口** | 不要开放 3306 到公网（只允许 127.0.0.1 访问） |
| **防火墙** | 只开放 80/443，关闭 8080 对外 |
| **HTTPS** | 用 Let's Encrypt 或 acme.sh 配免费 SSL 证书 |
| **Git 历史** | 如果代码推到了公开仓库，历史中已泄露的密码需要在阿里云吊销 |
